# Grey Fox Webflow scripts

The page motion scripts for greyfoxpartners.com, served to Webflow through jsDelivr.
One folder per page (home-v2, owners, investors). Each script is the single bundled motion layer for that page.
No secrets and no data: only front-end code that is already public on the site.

## Flow 3 layout (10/20)

- `core/` is the shared layer every Flow 3 page loads: `gfx-core.css` (tokens, field inks, bar, footer I) and `gfx-core.js` (field engine, bar, room reveals, footer I, Lenis and Webflow plumbing). It exposes `window.gfx`.
- `home/` is the Home layer. `tools/build.js` bundles core + home into `home/gfx-home.dist.js` and minifies both stylesheets into `*.dist.css` (no `.min.` names: jsDelivr re-minifies those and breaks SRI). `manifest.json` lists the SRI hash of each served file.
- `portal/` is the demo portal shown in the market room. It loads in an iframe through `srcdoc`, because jsDelivr serves `.html` as plain text.
- `pages/` (10/20) is the shared inner-page layer (Contact, Privacy; Team later) on the core. Each inner page adds its own folder (`contact/`, `privacy/`): `gfx-<page>.js`, `gfx-<page>.css` (extras) and `gfx-<page>.ported.css`, the local stylesheets as the page uses them, GENERATED by `audit/webflow-build/f3-contact/tools/css-port.js` in the prototype repo (do not edit by hand). `tools/build.js` writes `<page>/gfx-<page>.dist.js` (core + pages + page) and `.dist.css` (pages + ported + extras).
- Pages pin files by commit SHA: `https://cdn.jsdelivr.net/gh/brokencarry/greyfox-webflow-scripts@<sha>/home/gfx-home.dist.js`.
